## Overview

E-Heritage is a travel web application that helps users discover, explore, and plan trips to heritage sites and cultural destinations.

**Why E-Heritage?**

- 🏛️ **Heritage Discovery:** Browse and explore cultural heritage sites with rich location data.
- 🗺️ **Map Integration:** Interactive maps for location-based discovery.
- 📱 **Responsive UI:** Clean HTML/CSS/JavaScript frontend for seamless user experience.
- ⚡ **Node.js Backend:** Express server handling API routes and data management.
- 🗃️ **MongoDB Database:** Persistent storage for heritage site information.

## Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language:** JavaScript (Node.js)
- **Packages:** `express`, `mongoose`, `dotenv`

### Installation

1. **Clone the repository:**

    ```bash
    git clone https://github.com/soumya0424/E-Heritage
    cd E-Heritage
    ```

2. **Install dependencies:**

    ```bash
    npm install
    ```

3. **Set up environment variables:**

    Create a `.env` file and add your MongoDB URI and API keys.

### Usage

```bash
npm start
```
