# E-Heritage

A full-stack web application for exploring cultural heritage and travel destinations.

## Overview

E-Heritage is a travel platform that helps users discover, explore, and plan trips to heritage sites and cultural destinations.

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js / Express
- **Database:** MongoDB
- **APIs:** Google Maps, Location APIs

## Project Structure

```
E-Heritage/
├── backend/        # Express server and API routes
├── frontend/       # HTML/CSS/JS UI
└── public/         # Static assets
```

## Features

- Browse heritage sites and cultural destinations
- Interactive maps for location-based discovery
- User-friendly travel planning interface

## Getting Started

```bash
# Install dependencies
npm install

# Start the server
node backend/server.js
```
